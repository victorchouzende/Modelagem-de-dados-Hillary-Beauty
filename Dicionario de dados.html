PostgreSQL Supabase

Visão Geral do Projeto

Info

O banco de dados Hillary Beauty foi modelado para suportar todas as operações de uma clínica de estética. Abaixo estão as características principais da infraestrutura e regras de negócio gerais aplicadas.

Característica Detalhe
Tecnologia Base PostgreSQL hospedado no Supabase.
Total de Tabelas 11 Tabelas de negócio interligadas.
Segurança de Dados Row Level Security (RLS) ativo em 100% das tabelas. Acesso anônimo via API bloqueado.
Auditoria Automática Tabela dedicada (log_auditoria) alimentada por Triggers para rastrear alterações críticas no banco.
Chaves Primárias Todas as tabelas utilizam UUID gerados automaticamente (uuid_generate_v4()).

cliente

Cadastro Base
Coluna Tipo Restrições Descrição / Regras
id UUID PK Identificador único (uuid_generate_v4).
nome VARCHAR(100) NOT NULL Nome completo da(o) cliente.
telefone VARCHAR(20) NOT NULL, UNIQUE Usado para contato e lembretes de retorno.
data_nascimento DATE NULL Para promoções de aniversário.

profissional

Equipe
Coluna Tipo Restrições Descrição
id UUID PK Identificador único.
nome VARCHAR(100) NOT NULL Nome do especialista.
ativo BOOLEAN DEFAULT true Impede agendamentos se falso.

procedimento

Catálogo
Coluna Tipo Restrições Descrição / Regras
id UUID PK Identificador único.
nome VARCHAR(100) NOT NULL Ex: Botox, Limpeza de Pele.
valor_base DECIMAL(10,2) NOT NULL, > 0 Valor de referência.
perc_comissao DECIMAL(5,2) NOT NULL, 0-100 Percentual padrão para repasse.
intervalo_retorno_dias INTEGER NULL Dias sugeridos para novo agendamento.

agendamento

Agenda
Coluna Tipo Restrições Descrição / Regras
id UUID PK Identificador único.
cliente_id UUID FK NOT NULL Ref: cliente.id.
profissional_id UUID FK NOT NULL Ref: profissional.id.
data_hora TIMESTAMP NOT NULL Data e hora do compromisso.
status VARCHAR(20) CHECK Valores: 'Agendado', 'Concluído', 'Cancelado'.

atendimento

Operação
Coluna Tipo Restrições Descrição / Regras
id UUID PK Identificador único.
agendamento_id UUID FK UNIQUE 1:1 com Agendamento. Requer status='Concluído'.
procedimento_id UUID FK NOT NULL Procedimento realizado.
valor_final DECIMAL(10,2) NOT NULL, >= 0 Valor cobrado (pode incluir desconto).

pagamento

Financeiro
Coluna Tipo Restrições Descrição / Regras
id UUID PK Identificador único.
atendimento_id UUID FK NOT NULL Atendimento ao qual o pagamento se refere.
valor_pago DECIMAL(10,2) NOT NULL, > 0 Quantia paga nesta transação.

comissao

Financeiro
Coluna Tipo Restrições Descrição / Regras

historico_clinico

Prontuário
Coluna Tipo Restrições Descrição / Regras
id UUID PK Identificador único.
cliente_id UUID FK NOT NULL Cliente avaliado.
